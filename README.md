# Lume

### A fast, lightweight Sparx Maths Times Tables autocompleter.

> **Important:** Lume currently works with **Times Tables only**.

## Features

- **Fast** — designed to complete Times Tables with minimal delay.
- **No AI** — everything is handled locally with straightforward JavaScript logic.
- **Tampermonkey script** — simple to install and run directly in your browser.
- **Lightweight** — only around **400 lines of code**.
- **Open source** — inspect it, modify it, improve it, or contribute.
- **Focused** — built specifically for Sparx Maths Times Tables.

## Installation

### 1. Install Tampermonkey

Install the Tampermonkey browser extension if you do not already have it.

Supported browsers include:

- Chrome
- Edge
- Firefox
- Opera
- Other Chromium-based browsers

### 2. Install Lume

1. Open the Lume userscript.
2. Click **Install** in Tampermonkey.
3. Open Sparx Maths.
4. Navigate to **Times Tables**.
5. Lume will handle the rest.

## How It Works

Lume does **not** use AI, external AI APIs, or machine learning.

It uses lightweight JavaScript to interact directly with the Sparx Maths Times Tables interface.

This keeps the script:

- Fast
- Simple
- Predictable
- Easy to inspect

## Limitations

Lume currently supports:

- Sparx Maths Times Tables

Lume does not currently support:

- General Sparx Maths questions
- Written maths questions
- AI-generated answers
- Other Sparx Maths activities
